# Céleste ✦

Application Céleste — écran d'accueil kawaii (niveau maximal) avec Lumi, heures miroir, méditation, journal et lune.

## Stack

- React + Vite
- React Router pour la navigation (Accueil, Heures miroir, Méditer, Journal, Lune)

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Seule la page d'accueil est designée pour l'instant ; les autres routes affichent une page de type "bientôt disponible" en attendant leurs maquettes.
