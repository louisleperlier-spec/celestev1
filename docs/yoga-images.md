# Illustrations des postures de yoga

40 images à générer (ChatGPT ou autre), **une posture par image**, dans le même style que les 50 illustrations d’exercices de NÉA.

## Prompt à copier (remplacer la dernière ligne pour chaque posture)

```
Illustration 3D d'un mannequin anatomique masculin, chauve, peau gris clair mat, musculature réaliste et athlétique, sans visage marqué, sans vêtements ni logo.
Il réalise une posture de yoga sur un tapis invisible, vue de profil ou de trois quarts pour que la posture soit lisible.
Les muscles les plus étirés ou sollicités sont colorés en orange vif (#FF6B1A), le reste du corps reste gris.
Fond totalement transparent (PNG), pas d'ombre au sol, pas de texte, pas de décor. Image carrée 1024 × 1024, le corps entier visible et centré avec une petite marge.
Éclairage doux de studio, rendu propre et moderne.
Posture : <NOM> (<SANSKRIT>) — muscles en orange : <ZONES>.
```

Enregistre chaque image avec le nom de fichier indiqué (ex. `chien_tete_bas.png`) et envoie-les-moi : je les recadre, je les convertis et je les intègre dans l’app.
